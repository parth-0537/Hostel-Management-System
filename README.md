# Hostel Management System

A C++ console-based application designed to simplify hostel administration through student management, room allocation, check-in management, and file-based record storage.

## Features

- Student management
- Room management and allocation
- Warden management
- Hostel check-in management
- File-based data storage
- Record management using C++ file handling

## Technologies

- C++
- Object-Oriented Programming (OOP)
- File Handling
- GCC Compiler
- Windows Command Prompt

## Project Structure

- `Source/` — C++ source and header files
- `Data/` — Data files used to store hostel records
- `Executable/` — Compiled application
- `.gitignore` — Git exclusion rules

## Prerequisites

- Windows operating system
- GCC C++ compiler
- Windows Command Prompt (CMD)

## Installation and Usage

**1. Download the project**

Download the repository using the Code button on GitHub and extract the ZIP file.

**2. Verify the compiler**

Open Command Prompt and run:

    g++ --version

**3. Open the source directory**

Navigate to the `Source` directory containing the C++ files. Type `cmd` in File Explorer's address bar and press Enter.

**4. Compile the program**

    g++ *.cpp -o HostelManagement.exe

**5. Run the application**

    HostelManagement.exe

The application will start in Command Prompt if compilation succeeds.

## Data Management

The application uses text files to store records. Keep the required data files in their expected locations to ensure the application can read and save information correctly.
